دليل رفع مشروع بترونيل يمن للطاقة على GITHUB و RENDER
شركة بترونيل يمن للطاقة - 2026
====================================================================

هذا المجلد يحتوي على النسخة النظيفة والكاملة والمجهزة خصيصاً للرفع على مستودعك في GitHub والاستضافة.

--------------------------------------------------------------------
الخيار 1: الرفع السريع عبر واجهة موقع GitHub (طريقة السحب والإفلات)
--------------------------------------------------------------------
1. افتح حسابك على موقع https://github.com
2. افتح مستودع المشروع (Repository) الخاص بك.
3. اضغط على زر "Add file" ثم اختر "Upload files".
4. حدد جميع الملفات والمجلدات الموجودة داخل هذا المجلد:
   (بما فيها مجلد engine ومجلد tests وجميع ملفات html و js و css و db.json والصور).
5. اسحبها وافلتها في صفحة GitHub.
6. انتظر حتى يكتمل شريط رفع الملفات، ثم اضغط على الزر الأخضر "Commit changes".

--------------------------------------------------------------------
الخيار 2: الرفع عبر أوامر Git (إذا كان Git مثبتاً على حاسوبك)
--------------------------------------------------------------------
افتح موجه الأوامر (CMD أو PowerShell) داخل هذا المجلد، ونفذ:

git init
git add .
git commit -m "تحديث هندسي وبرمجي شامل - بترونيل يمن للطاقة"
git branch -M main
git remote add origin https://github.com/اسم_حسابك/اسم_المستودع.git
git push -u origin main --force

--------------------------------------------------------------------
الربط والتحديث التلقائي على Render:
--------------------------------------------------------------------
- بمجرد رفع التعديلات إلى GitHub، ستقوم استضافة Render بسحب التحديثات وإعادة تشغيل الموقع تلقائياً خلال دقيقة واحدة.
- رابط موقعك على رندر: https://petronilsolar.onrender.com
