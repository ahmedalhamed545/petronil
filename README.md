# حاسبة بترونيل يمن للطاقة الشمسية | Petronil Yemen Solar Calculator

موقع إلكتروني تفاعلي متكامل من صفحة واحدة (Single Page Application) لشركة **بترونيل يمن للطاقة**، يحتوي على حاسبة ذكية لحساب احتياجات العملاء من الألواح الشمسية والبطاريات والعواكس الهجينة بناءً على مدخلاتهم من الأجهزة وساعات التشغيل.

---

## 🛠️ التقنيات المستخدمة
* **HTML5**: الهيكل البنائي وعناصر الصفحة.
* **CSS3 (Vanilla)**: تصميم زجاجي عصري (Glassmorphic) يدعم الوضع الداكن (Dark) والمضيء (Light) وتنسيقاً خاصاً بالطباعة (Print CSS).
* **JavaScript (ES6+)**: محرك العمليات الحسابية وحساب الأحمال وعرض التكاليف بشكل لحظي وتفاعلي.

---

## 📂 هيكل ملفات المشروع
* `index.html` - الملف الرئيسي لهيكل الموقع وأقسامه.
* `styles.css` - ملف الأنماط والتنسيقات والتأثيرات الحركية والتجاوب مع الجوال.
* `calculator.js` - محرك حسابات الأحمال وصيغ الطاقة والأسعار والعملات.
* `README.md` - هذا الملف التعريفي بالمشروع.

---

## 📐 خوارزمية الحسابات البرمجية المطبقة
1. **الألواح الشمسية (610 واط)**:
   $$\text{عدد الألواح} = \frac{\text{إجمالي واط الأجهزة المضافة} \times 1.5}{610}$$
   *إذا كان الناتج عدداً فردياً، يتم تلقائياً زيادة لوح واحد ليصبح العدد زوجياً دائماً لضمان اتزان توصيل الألواح.*

2. **البطاريات وتخزين المساء**:
   * **طاقة المساء المطلوبة**: إجمالي قدرة أجهزة الليل بالوات × ساعات التشغيل المحددة بالليل × 1.15 (زيادة 15% معامل أمان للمساء).
   * **نوع البطارية**:
     * **ليثيوم (48V 100Ah = 4.8kWh)**: عمق تفريغ 90%.
     * **جل/أسيد (12V 150Ah = 1.8kWh)**: عمق تفريغ 50%.

3. **العاكس الهجين (Inverter)**:
   * يتم تحديد قدرته تلقائياً بناءً على مجموع قدرة الأجهزة الكهربائية المفترض تشغيلها معاً (مع معامل تزامن ذكي وتطبيق 20% هامش أمان إضافي).

## 🚀 كيفية تشغيل المشروع واستعراضه
1. قم بفتح مجلد المشروع في جهازك.
2. انقر نقراً مزدوجاً فوق ملف **`index.html`** لفتحه فوراً في متصفح الويب الخاص بك.
3. لتشغيل خادم محلي سريع (اختياري)، يمكنك كتابة الأمر التالي في سطر الأوامر داخل مجلد المشروع:
   ```powershell
   python -m http.server 8000
   ```
   ثم تصفح الرابط: `http://localhost:8000`.
