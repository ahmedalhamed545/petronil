# منصة شركة بترونيل يمن للطاقة | Petronil Yemen Solar Platform

منصة ويب متكاملة وتفاعلية لحساب وتصميم منظومات الطاقة الشمسية وبيع منتجاتها، باسم **بترونيل يمن للطاقة**، مع لوحة إدارة ذكية ومحرك محاكاة هندسية على مدار 24 ساعة.

---

## 🌟 الميزات الرئيسية للمنصة
- **وكالة Crown Micro الرسمية:** دعم واعتماد إنفرترات كراون مايكرو العالمية (Crown Elego 3.2kW و Elego Pro 6kW) بجانب إنفرترات Deye وألواح N-Type وبطاريات LiFePO4.
- **التحديث التفاعلي الفوري:** حساب القدرة المركبة (W/kW)، الحمل المتزامن، تيار الإقلاع، والطاقة اليومية والشهرية (kWh) لحظياً عند تعديل أي مدخل.
- **محاكاة هندسية 24 ساعة (96 خطوة):** رصد توازن الطاقة، شحن وتفريغ البطاريات، ومعالجة فترات انقطاع الشبكة الحكومية وتجاوز منتصف الليل بدقة.
- **نظام مطابقة مالي وهندسي ذكي:** استبعاد أي منتجات غير مكتملة أو بأسعار صفرية، مع منع استقلالية 100% المضللة عند العجز أو انعدام الأحمال.
- **العملة وصلاحية العرض:** اعتماد الدولار الأمريكي ($) كعملة افتراضية لمنع تذبذب الصرف، مع خيار تفعيل الريال اليمني عند الطلب، وتحديد صلاحية عرض السعر ديناميكياً من لوحة الإدارة.
- **عرض سعر وجدول كميات رسمي (BOM & PDF):** إصدار وثيقة عرض سعر مطابقة للمواصفات مع إمكانية التصدير إلى PDF والمشاركة المباشرة عبر WhatsApp.
- **تصميم Mobile-First:** متجاوب بالكامل مع كافة الشاشات (320px, 360px, 390px, 430px) ومنع التمرير العرضي والتكبير التلقائي على iOS Safari.
- **لوحة إدارة متكاملة:** إدارة الطلبات (Leads)، المخزون والأسعار، الأجهزة، المعايير الهندسية، والمستخدمين والصلاحيات.

## 🚀 التشغيل المحلي (Local Development)

```bash
# 1. تثبيت الحزم البرمجية
npm install

# 2. تشغيل خادم الموقع
npm start
```

يفتح الموقع على: `http://localhost:3000`

---

## ☁️ النشر على منصة Render (Render Deployment)

1. ارفع هذا المجلد مباشرة إلى مستودع جديد على **GitHub**.
2. في منصة **Render.com**، اختر **New Web Service** واربط المستودع.
3. الإعدادات المطلوبة:
   - **Environment:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `node server.js`
4. اضغط **Create Web Service** وسيعمل الموقع تلقائياً مع شهادة أمان SSL مجانية.
